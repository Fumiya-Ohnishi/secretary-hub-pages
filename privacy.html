プライバシーポリシー

制定日: 2026年11月12日

「AI会社 秘書ハブ」(以下「本ツール」)は、運営者が自分のパソコンの中だけで使う管理ツールです。Google のアカウントで許可された範囲の情報を、次のとおり扱います。

1. 取得する情報

運営者自身の YouTube チャンネルの分析の数字(再生数・総再生時間・平均視聴時間・高評価数・登録者の増減など)と、チャンネル名・動画の題名です。利用する権限は、読み取り専用の yt-analytics.readonly と youtube.readonly だけです。

2. 使い道

運営者が自分の投稿の結果を振り返り、改善するためだけに使います。広告・販売・第三者への提供には使いません。

3. 保存する場所

取得した数字と、Google から受け取った認証の情報(更新用のトークン)は、運営者のパソコンの中にだけ保存します。外部のサーバーには送りません。パスワードは受け取りません。

4. 削除

運営者は、Google アカウントの設定(https://myaccount.google.com/permissions)から、いつでも本ツールへの許可を取り消せます。取り消すと、本ツールは数字を取得できなくなります。保存した数字は運営者のパソコンから削除できます。

5. Google API の利用

本ツールが Google API から受け取った情報の利用は、Google API サービスのユーザーデータに関するポリシー(限定的な使用の要件を含む)に従います。
